# LiveLib Metadata для Calibre v0.6.0

## Новые возможности

- **Отдельный плагин LiveLib Reading Dates.** Сохраняет даты прочтения выбранных книг в пользовательскую колонку даты. Настройки задаются отдельно для каждой библиотеки; перезапись заполненных дат включается явно.
- **Точная дата прочтения.** Новый публичный список LiveLib позволяет сохранить день прочтения; если доступен только месяц или год, исходная точность сохраняется

## Установка и обновление

Скачайте `LiveLib.Metadata.zip` из файлов релиза и установите через **Настройки → Плагины → Загрузить плагин из файла** (`Preferences → Plugins → Load plugin from file`). При обновлении новый архив заменит прежнюю версию. После установки перезапустите Calibre.

Для личных оценок и дат прочтения откройте **Настройки → Загрузка метаданных**, выберите **LiveLib Metadata** и нажмите **«Настроить выбранный источник»**. Укажите имя пользователя LiveLib и разрешите загрузку полей **«Оценка»** и **«Комментарии»**. В этой версии дата прочтения записывается в комментарии к книге.

Для записи даты в отдельную колонку установите необязательный `LiveLib.ReadingDates.zip`, перезапустите Calibre и добавьте **«Загрузить даты прочтения LiveLib»** в **Настройки → Панели инструментов и меню**.
