# LiveLib Metadata для Calibre v0.5.1

Все изменения после версии 0.3.3 из PR [№1](https://github.com/Ollisteka/calibre-livelib-metadata-plugin/pull/1), [№3](https://github.com/Ollisteka/calibre-livelib-metadata-plugin/pull/3), [№4](https://github.com/Ollisteka/calibre-livelib-metadata-plugin/pull/4) и [№5](https://github.com/Ollisteka/calibre-livelib-metadata-plugin/pull/5), включая изменения версий 0.3.4, 0.4.0 и 0.5.0.

## Новые возможности

- **Ссылки на книгу сразу в трёх сервисах.** Один результат поиска может содержать идентификаторы LitRes, LiveLib и FantLab. Другие источники дополняют недостающие сведения, сохраняя уже заполненные поля результата. Если нельзя однозначно выбрать дополнительную ссылку, плагин её не добавляет.
- **Выбор источников.** LitRes, LiveLib и FantLab можно включать и отключать по отдельности в настройках LiveLib Metadata. По умолчанию включены все три. Отключённый сервис не используется ни для сведений о книге, ни для обложек.
- **Удобнее работать со ссылками.** Calibre показывает названия сервисов и ссылки на все найденные источники. Плагин распознаёт адреса книг из LitRes, LiveLib и FantLab и умеет загружать сведения по ссылкам на произведения и издания FantLab.
- **Личная оценка и дата прочтения из LiveLib.** Укажите **«Имя пользователя LiveLib»**, чтобы загружать свою оценку в поле оценки Calibre. Оценка и дата прочтения также добавляются в **«Детали издания LiveLib»** в комментариях к книге. Данные берутся из публичной полки **«Прочитал»** для того же издания книги.
- **Выбор оценки, если личной нет.** Настройка **«Если личная оценка LiveLib не найдена»** позволяет не переносить оценку — это вариант по умолчанию — или использовать общую оценку книги из включённых источников. Найденная личная оценка всегда имеет приоритет. Выбор действует и при недоступном профиле или истечении времени поиска.
- **Сохранение точности даты прочтения.** Если LiveLib указывает только месяц или год, в комментарии переносится именно он. При повторном прочтении используется самая новая запись на полке.
- **Приоритет обычных книг в LitRes.** При совпадении названия и авторов плагин предпочитает электронные и бумажные издания аудиокнигам. Если доступна только аудиокнига, она остаётся в результатах. Явно указанный идентификатор аудиокниги также учитывается.
- **Поиск с учётом уже известной книги.** Если книга найдена по сохранённому идентификатору, другие сервисы дополняют сведения о ней. Даже при большом числе совпадений в результатах остаётся место для каждого источника в пределах общего ограничения в шесть результатов.

История чтения загружается постепенно и запоминается на пять минут, чтобы не скачивать её заново при каждом запросе. Недоступность профиля не мешает обычной загрузке сведений о книге. Пустое имя пользователя или отключение LiveLib выключает загрузку истории; при поиске только обложек она тоже не запрашивается.

## Исправления ошибок

- Исправлена загрузка обложек LiveLib, которая могла завершаться ошибкой из-за способа хранения картинки на странице. Теперь поддерживаются разные варианты записи обложек, а некорректные значения пропускаются.
- Обложки разных сервисов больше не путаются, если у книг совпадают номера идентификаторов.
- Обложку можно загрузить по сохранённому идентификатору книги, даже если её ещё нет во временной памяти плагина.
- Найденные на LiveLib книги и доступные обложки больше не пропадают из результатов, если не удалось открыть подробную страницу книги.
- Исправлена загрузка книг LiveLib с несколькими авторами: плагин сохраняет всех соавторов и не завершает загрузку с ошибкой.
- Исправлено отображение оценок: например, личная оценка 4 из 5 теперь отображается как четыре звезды, а не пять.
- Ссылки FantLab ведут на страницы сайта для читателей и сохраняют различие между произведением и конкретным изданием. Старые идентификаторы FantLab, состоящие только из цифр, нужно обновить повторной загрузкой сведений о книге.
- Исправлена обработка страниц с эмодзи и некоторыми редкими символами.
- Время поиска распределяется между сервисами, чтобы один источник не расходовал всё время ожидания. После отмены плагин не начинает следующие этапы поиска.
- Исправлено обновление установленного плагина: старые и новые части программы больше не смешиваются при замене ZIP-файла.

## Рефакторинг — внутренние улучшения

- Код разделён на небольшие части: работа с каждым сервисом, поиск книг, объединение сведений и загрузка обложек. Это упрощает дальнейшие исправления и добавление возможностей; правила сравнения названий и авторов сохранены.
- Удалён неиспользуемый код, улучшено освобождение сетевых соединений после запросов.
- Обеспечена загрузка всех частей плагина из установочного ZIP-файла.

## Тестирование и сборка

- Добавлены автоматические проверки поиска, ссылок, сведений о книгах, обложек, отмены загрузки и обработки ошибок. Проверки работают без интернета и установленного Calibre.
- Проверки запускаются на GitHub при изменениях в main и при предложении изменений для этой ветки. Их также можно запустить вручную. В README добавлены инструкции для Windows и Linux.
- Добавлены проверки установочного архива и отдельная проверка работы с настоящим Calibre на подготовленных примерах. Устранена зависимость некоторых проверок от скорости компьютера.
- Добавлен способ собрать установочный ZIP-файл с помощью Python на Windows и Linux. В архив не попадают временные и служебные файлы разработки.

## Установка и обновление

Скачайте `LiveLib.Metadata.zip` из файлов релиза и установите через **Настройки → Плагины → Загрузить плагин из файла** (`Preferences → Plugins → Load plugin from file`). При обновлении новый архив заменит прежнюю версию. После установки перезапустите Calibre.

Для личных оценок и дат прочтения откройте **Настройки → Загрузка метаданных**, выберите **LiveLib Metadata** и нажмите **«Настроить выбранный источник»**. Укажите имя пользователя LiveLib и разрешите загрузку полей **«Оценка»** и **«Комментарии»**. В этой версии дата прочтения записывается в комментарии к книге.
